## Ejercicios

### Ejercicio 1.1: formulario de registro

Formulario en HTML, CSS y JavaScript con validación de los campos antes de continuar.

**Ejecución:** abre `PEC1_Ej1_1/index.html` en un servidor local, por ejemplo, con la extensión Live Server de Visual Studio Code.

### Ejercicio 1.2: conversor de moneda

Aplicación que obtiene tipos de cambio mediante una petición a un servicio externo. Incluye controles de carga y de error.

**Ejecución:** abre `PEC1_Ej1_2/index.html` desde un servidor local. La consulta de tipos de cambio requiere conexión a Internet y una clave configurada en `PEC1_Ej1_2/env.js`.

### Ejercicio 1.3: reserva de asientos de cine

Aplicación para seleccionar una película, elegir asientos disponibles y consultar el total. Guarda en el almacenamiento local del navegador la selección de asientos y la película. También permite seleccionar una moneda y convertir los precios usando los tipos de cambio obtenidos desde el servicio externo.

**Ejecución:** abre `PEC1_Ej1_3/index.html` desde un servidor local. La conversión requiere conexión a Internet y una clave configurada en `PEC1_Ej1_3/env.js`. La selección guardada permanece en el almacenamiento local del navegador utilizado.

## Dificultades y mejoras

En los ejercicios que consultan tipos de cambio, la aplicación depende de la conexión y disponibilidad del servicio externo. Para probar la conversión, selecciona una moneda y espera a que termine la consulta.
